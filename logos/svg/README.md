Tous les fichiers sont **autonomes, transparents, scalables sans perte**.

## Import dans Figma

1. Ouvrez Figma
2. **Drag-and-drop** les .svg directement dans votre canvas, OU
3. Menu **File → Import**, sélectionnez les .svg

Les SVG arrivent en groupes de formes vectorielles 100% éditables (couleurs, tailles, formes).
Pour les fichiers avec texte ("MT" sur 04, 10, 16, 25) : si vous n'avez pas Satoshi installé,
Figma proposera une substitution — ou vous pouvez **convertir le texte en path** dans Figma
(clic droit sur le texte → "Outline stroke" ou "Flatten").

## Import dans Illustrator / Affinity Designer

Glissez-déposez. Idem pour les fontes.
